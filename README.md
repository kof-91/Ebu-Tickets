# Ebu-Tickets
тикетный бот для обращений и поддержки через систему тикетов

что умеет
- регистрация через /start, с проверкой на подписанные телеграмм каналы (можно заменять на любые свои)
- создание тикетов /ticket
- анонимный/не анонимный режим тикета
- добавление фото
- ответ от администратора проходит тоже в боте, администратору отсылается тикет от пользователя на который он может ответить

код очень монолитный, говорю сразу  
 база данных на основе sqlite, для просмотра советую https://sqliteviewer.app/  
 а для правки расширение sql editor в vs code  

## требования
- python3.10 или новее
- aiogram
- aiosqlite
- python-dotenv

    пример .env  
    BOT_TOKEN=твой_токен_бота  
    ADMIN_ID=айди_администратора_бота
